# Registro de Horas HSA

Página para llevar el registro mensual de horas de funcionarios HSA, con tope mensual de 180 horas, feriados × 1,25, permisos administrativos AM/PM y hoja imprimible.

Página: https://abgdanielm.github.io/registro-horas-hsa/

Los datos quedan guardados solo en el dispositivo de cada usuario.

Herramienta independiente; no es un sistema oficial del SAG.
